## Fleet Handset

![Scrolling Fleet Handset with portraits, measured distances and disabled out-of-range controls](/assets/hytale0.7/native/fleet-handset-roster.png)

*Hytale 0.7.4: search by name, sort the fleet and scroll through linked robots. Distant robots remain visible while editing and control are disabled.*

![Robot bust, name field and six-colour editor beside the selected fleet row](/assets/hytale0.7/native/fleet-handset-editor.png)

*Hytale 0.7.4: use the portrait pencil to preview a name or colour change. Save changes to apply them; the editor X discards the draft. Unlink has a separate confirmation.*
