# Asset and dependency notes

Optimus Link is an independent fan mod inspired by Optimus. Tesla and Hytale names identify the inspiration and target game; this project is not affiliated with either company. No corporate logos are included.

The mod's cuboid models, textures, icons and animation clips are original project assets. Its sound families were generated through the connected ElevenLabs Sound Effects workflow. The guide's logo and banner are original generated artwork; they are illustrations, not game screenshots. Private source takes and generation records are retained outside this repository.

Hytale server libraries and base-game assets are external dependencies and are not redistributed here. Recipes reference native ingredient and crafting IDs. Gson is supplied by the target server runtime and is not bundled in this JAR. The documentation build uses MkDocs and its bundled Read the Docs theme; their generated attribution remains in the site footer.

No distribution license has been selected for Optimus Link. These notes do not grant redistribution rights to game files or third-party dependencies.
